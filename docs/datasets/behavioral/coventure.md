# Coventure

## Overview

| Field | Details |
|-------|---------|
| **Cohort Name** | Coventure |
| **Description** | A longitudinal population-based cohort study tracking 3,801 adolescents recruited from 31 schools in the Greater Montreal area, designed to evaluate adolescent substance use, cognitive development, and the emergence of mental health issues or psychotic-like experiences |
| **N Subjects** | 3,801 adolescents (51% female) |
| **Timepoints** | yearly from grades 7 to 11 (September 2012 to 2018) |
| **Data Types** | Behavioral questionnaires, self-reported metrics on substance use frequency, sleep quality parameters, and psychotic-like experiences |
| **Data Location** | *TBD* |
| **PI / Contact** | Dr. Patricia Conrod |
